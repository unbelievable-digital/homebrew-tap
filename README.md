# Unbelievable Digital Homebrew tap

```sh
brew install --cask unbelievable-digital/tap/unbelievable-jungle
```

| Cask | App |
|------|-----|
| `unbelievable-jungle` | [Unbelievable Jungle](https://jungle.unbelievable.digital) — a desktop pet (a cat, a dog or a monkey) that lives on top of your windows. macOS 14 or later. |

The app updates itself with Sparkle, so `brew upgrade` leaves it alone (`auto_updates true`). The cask is
bumped automatically by the app's release script after every release.
